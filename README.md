# Lieth Organigramme Assistant

Windows flowchart editor with ARSEF branding. Each person signs in with an identifier created by the Directrice. Their editable diagrams, missions, and settings remain available in their local Windows profile and are copied into an AES-256 encrypted personal vault in the shared OneDrive `Diva Productivite` folder.

Diva Productivité opens a prefilled email in the computer’s default mail app, where the responsible person reviews it and sends it. Its calendar button opens a prefilled event in the computer’s default calendar app. The Directrice creates usernames, assigns roles, and can issue temporary replacement passwords without seeing anyone’s password. Her offline recovery key must be kept outside the shared OneDrive.

Updates are optional, downloaded only after confirmation, SHA-256 verified, and installed per-user. The updater backs up the installed app and restores it if installation fails; user settings are outside the install directory and are retained.

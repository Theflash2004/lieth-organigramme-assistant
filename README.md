# Lieth Organigramme Assistant

Offline Windows flowchart editor. It stores user settings in `%AppData%\Lieth Organigramme Assistant`, never sends telemetry, and checks only the public GitHub Releases endpoint for updates.

Updates are optional, downloaded only after confirmation, SHA-256 verified, and installed per-user. Inno Setup rolls back a failed installation; user settings are outside the install directory and are retained.
